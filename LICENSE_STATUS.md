# License status

This repository is technically prepared for review but the custom research-code license is not yet confirmed.

| Material | Status |
|---|---|
| nnU-Net upstream code | Apache License 2.0 at the pinned upstream revision |
| Custom trainer overlays | Authorship/public redistribution approval must be confirmed |
| Dataset preparation scripts | Authorship/public redistribution approval must be confirmed |
| BraTS MRI and labels | Not included; governed by challenge/Synapse terms |
| Pseudo-labels, case lists, split, metadata | Not included; redistribution rights must be checked |
| Model checkpoints | Not included; redistribution rights must be checked |

Do not assume that the Apache-2.0 license of nnU-Net automatically licenses custom files layered onto it. Before a public push, the rights holder should choose a license, add a root LICENSE file, and complete CITATION.cff.example.

This document is a release checklist, not legal advice.
